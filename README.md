## 先把四个词分清楚：机房 IP、原生 IP、住宅 IP、双 ISP

这四个词经常被混着用，但它们不在同一个维度上。

**原生 IP** 说的是归属。按朝暮数据给出的定义，IP 地址的运营商所在国家和服务器所在地一致，就算原生 IP。一台放在法兰克福的机器，分到德国运营商名下的 IP 段，就是德国原生 IP。反过来，拿美国运营商的 IP 段广播到德国机房，地理位置对不上，就不算。

**住宅 IP** 说的是来源。它是 ISP 分配给家庭或个人用户的地址，来自真实的家宽线路。这类 IP 在某些平台上更容易被当成真人用户。注意，原生 IP 不一定是住宅 IP——机房也可以持有本国运营商的 IP 段，那就是“德国原生 IP，但属于 IDC 机房 IP”。

**双 ISP** 说的是背书层数。同一台机器上的 IP 属性由两个运营商同时支撑，比单 ISP 再加固一层。这是商家自己的产品设计，不是行业标准术语，效果因段而异。

**机房 IP** 是反面参照。各大平台早就建了 IDC 段库，一段 IP 上挤着几十台 VPS，风控模型看一眼就知道。

这四层想清楚，再去比价格，就不会被“德国原生 IP、月付 49 元”这种标题带偏——那个价大概率是机房原生 IP，不是住宅。

关于“纯净度”，这里要说一句竞品文章基本不提的话。第三方脚本给出的 scamalytics 分数、ping0 判定、IP 风险等级，都只是各家数据库自己的算法结果，不同脚本对同一台机器经常给出不同结论。朝暮数据在自己的 FAQ 里写得很直白：某些网站的 IP 欺诈值检测并没有评分依据，IP 地址也没有“纯净、干净、新老”的说法，TikTok 这类公司有自己的 IP 地址库和检测手段。所以正确的理解是：**你买的是 IP 的属性差异，不是一张“不会被风控”的保单。** 任何把检测分数写成风控保证的文章，都可以关掉。

## 常见问题

**原生 IP 和住宅 IP 到底差在哪？**

原生指归属地对得上——IP 的运营商国家和服务器所在地一致。住宅指来源是 ISP 分配给家庭用户的地址。一台德国机器可以同时是原生 IP 和机房 IP（这很常见），也可以是原生 IP 加住宅 IP（这才稀缺）。买之前看清楚商品页写的是哪一个，别看到“原生”就以为拿到了“住宅”。

**双 ISP 真的有用吗？**

它加固的是 IP 的住宅属性，让同一台机器上的 IP 有两个运营商背书。这是产品设计层面的差异，确实区别于单 ISP。但它换来的是“起点更好”，不是“平台不拦你”。把它当加分项，别当免死金牌。

**德国 VPS 国内访问慢怎么办？**

两个办法：一是中转，用香港或日本节点跳一下，这也是官方建议的路子；二是开 BBR 改善拥塞控制。两个都改变不了物理距离。如果你的业务对国内访问速度是硬要求，正确做法不是优化德国机器，而是换成带 CN2 GIA 或 CMIN2 的德国机型，或者干脆把机器放到香港、日本。

**能装 Windows 吗？**

能，全系支持。但年付特价版只有 10GB 系统盘，装 Windows 不现实。要 Windows 从进阶版（40GB）起。

**48 小时退款怎么退？**

下单后 48 小时内提交申请，德国 VDS 属于特殊产品，退款退到网站余额而非原路返还。介意这一点的，先在年付特价版或基础版上小额试，别一上来就买豪华版。
